# Calculadora no Flowgorithm

**Aluno:** Davi Carvalho Macedo

## Objetivo

Desenvolver, utilizando o Flowgorithm, uma calculadora com 20 funções diferentes, aplicando os conceitos de lógica de programação, entrada e saída de dados, variáveis, operadores e estruturas de decisão.

## Descrição do funcionamento

O programa exibe um menu com 20 opções numeradas de 1 a 20. O usuário digita o número correspondente à operação desejada, informa os dados solicitados (peso, altura, valores numéricos, etc.) e o programa processa essas informações, exibindo o resultado na tela. Caso o usuário digite um valor fora do intervalo de 1 a 20, o programa informa que a opção é inválida.

## Funções implementadas

| Nº | Função |
|----|--------|
| 1  | Cálculo do IMC (Índice de Massa Corporal) — **obrigatória** |
| 2  | Cálculo de área de figuras geométricas (quadrado, retângulo, triângulo e círculo) — **obrigatória** |
| 3  | Soma |
| 4  | Subtração |
| 5  | Multiplicação |
| 6  | Divisão (com tratamento de divisão por zero) |
| 7  | Média aritmética |
| 8  | Porcentagem |
| 9  | Regra de três simples |
| 10 | Conversão de temperatura (Celsius para Fahrenheit) |
| 11 | Conversão de unidades (quilômetros para milhas) |
| 12 | Cálculo de perímetro do retângulo |
| 13 | Cálculo de volume do cubo |
| 14 | Cálculo de juros simples |
| 15 | Cálculo de desconto |
| 16 | Cálculo de velocidade média |
| 17 | Cálculo de consumo de combustível (km/l) |
| 18 | Identificação de número par ou ímpar |
| 19 | Comparação entre dois valores |
| 20 | Cálculo de potência |

## Funções obrigatórias

- **IMC:** opção 1 do menu. Solicita peso (kg) e altura (m), calcula o IMC e classifica o resultado em abaixo do peso, peso ideal, sobrepeso ou obesidade.
- **Área de figuras geométricas:** opção 2 do menu. Apresenta um submenu com 4 figuras (quadrado, retângulo, triângulo e círculo) e calcula a área de acordo com a figura escolhida.

## Instruções de execução

1. Baixe e instale o [Flowgorithm](http://www.flowgorithm.org/download/) (gratuito).
2. Abra o programa e clique em **File > Open**.
3. Selecione o arquivo `calculadora.fprg` desta pasta.
4. Clique em **Run** (ou pressione F5) para executar o fluxograma.
5. Digite o número da opção desejada (1 a 20) e siga as instruções exibidas na tela.
